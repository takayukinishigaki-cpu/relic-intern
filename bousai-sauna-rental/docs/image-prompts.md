# 画像生成プロンプト集（ChatGPT用）

サイト内の「画像差し替え予定（画像①〜④）」の枠と、共有用のOGP画像（画像⑤）を作るためのプロンプトです。
ChatGPT（画像生成）に、**「共通の指定」＋各画像のプロンプト**をまとめて貼り付けてください。

## 使い方

1. ChatGPT の新しいチャットに、下の「共通の指定」を貼る
2. 続けて、作りたい画像のプロンプトを貼って送信する
3. 気に入った画像をダウンロードし、`public/images/` に指定のファイル名で保存する
4. `src/pages/Home.tsx` で該当の `ImagePlaceholder` に `src` を追加する
   例：`<ImagePlaceholder label="みんなで組み立て" promptId="画像①" src="/images/fun-build.jpg" ... />`

> 同じチャットで続けて作ると、タッチや人物の雰囲気がそろいやすくなります。
> 生成した画像は、利用規約や肖像の扱いを確認してから公開してください。

## 共通の指定（最初に必ず貼る）

```
これから、企業向けの防災訓練サービス「防災サウナレンタル」のWebサイトに使う画像を何枚か作ります。すべての画像で、次のトーンをそろえてください。

【サービスの内容】
会社の仲間10〜15人が、テント型のサウナ（薪ストーブつきの持ち運べるサウナテント）を自分たちで組み立てて入る防災訓練。災害で燃料・水・ガスが止まっても、少ない燃料と水で温まり、清潔を保てることを体験で学ぶ。食事も一緒に楽しむ、明るい雰囲気の訓練。

【画風】
・写真のようにリアルな、明るく温かい雰囲気の写真風
・自然光。午後のやわらかい日差し
・色味：落ち着いた紺色（#1b2a4a 付近）と、温かいオレンジ（#ef7a2f 付近）がアクセントとして入る
・清潔感があり、企業の担当者が社内で見せても安心できる品のある雰囲気

【人物】
・日本の会社員。20代〜50代、男女まじり
・服装：動きやすいカジュアル（作業着風のジャケット、パーカー、Tシャツなど）。サウナ中は水着やサウナポンチョ、タオル
・自然な笑顔。カメラ目線ではない
・露出は控えめに。肌の露出が多すぎる表現は避ける

【避けること】
・文字、ロゴ、看板、ウォーターマーク
・実在のブランド名や商品がわかるもの
・災害現場の悲惨な描写、けが、危険に見える火の扱い
```

## うまくいかないときの追加指示（例）

- 人が多すぎる → 「人数を3人に減らしてください」
- 雰囲気が暗い → 「もっと明るく、日差しを強めにしてください」
- 海外っぽい → 「日本の地方都市の会社の駐車場らしい背景にしてください」
- 露出が気になる → 「全員サウナポンチョを着た姿にしてください」
- 色味がずれる → 「テントの色をオレンジ（#ef7a2f）にしてください」
